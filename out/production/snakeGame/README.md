# SNAKE GAME

Trabalho desenvolvido para a disciplina de Programação BackEnd no
Colégio Guaíra. Escrito em linguagem JAVA por Samuel Pereira. O código 
é um jogo exclusivamente jogado por uma pessoa que controla um 
personagem, uma cobra que percorre o cenário comendo frutas para 
crescer.


# Regras 

1. Aperte qualquer botão para começar.
2. Use as teclas de direção ou W, A, S, D para movimentar a cobra.
3. O objetivo é comer as frutas, crescer e não morrer.
4. Quanto mais frutas a cobra comer, mais rápido ficará.
5. Sobreviver ao máximo de tempo
6. Não pode transpassar o corpo.
7. Não pode bater nas bordas.
